# 蜂鸣器播放与曲目

曲目是 `Song`，每首一个 `.hpp`，放在 `lib/melody/music/`，由 `tools/midi_to_song.py` 从 MIDI 生成。

```cpp
#include "melody/melody.hpp"
#include "melody/music/you.hpp"

Melody melody;         // 使用板载蜂鸣器，主循环约 1 kHz 调用 melody.update()
melody.play(G5G5G5);   // 普通模式：提示音
melody.play_poly(YOU); // 复音模式：演奏
```

## 数据结构

| 类型 | 含义 |
| --- | --- |
| `Note {midi, len}` | MIDI 音符号（0 为休止）与时长（单位 10 ms，最大 2550 ms） |
| `Voice` | 声部：一条单音序列 `span<const Note>`；相邻同音条目连续发声，重击之间必须有休止 |
| `Part` | 声部组 `span<const Voice>`，第 0 个为主声部，其余为内声部 |
| `Song {melody, chords}` | 旋律组（主声部取最高音）与伴奏组（主声部取最低音）；无伴奏时 `chords` 为空 |

两层 span 的原因：各声部长度不同，无法放进二维数组；声部由生成器离线分配，板上不做动态分配。

播放器按值保存只读 `Config`，载波、包络与 AGC 参数直接读取 `config`；采样周期、增益步长和采样数在构造时计算并保留，避免中断内重复换算。

## 两种模式

| 接口 | 播什么 | 实现 |
| --- | --- | --- |
| `play` | 只播旋律主声部 | 直驱方波：只在音高变化时调用 `Buzzer::set_tone`/`mute`，不占用中断 |
| `play_poly` | 全部声部 | PWM-DAC：载波 `carrier_hz`（默认 32 kHz，20~64 kHz 内 1 kHz 的整数倍）即采样率，DMA 半满/全满中断每 1 ms 内合成一块占空比，块长按载波换算 |

普通模式与旧播放器等价：旋律主声部即“最高音抢占”的单音结果。两种模式互相打断，后一次播放生效。

复音合成（方案来源见 `tasks/02-buzzer_timbre/README.md`）：

- 每个声部为 PolyBLEP 限带方波乘衰减包络；包络由 `Envelope {decay, sustain}` 描述
- 组内按各声部幅度平方和开方归一，组间按 `melody_share` 分配摆幅；无伴奏时旋律独占
- 总 AGC 补偿包络衰减：旋律短暂休止（不超过 `agc.hold`）时保持，前奏、间奏按伴奏调节
- 松开后 30 ms 淡出、首尾 20 ms 占空比斜坡，分别消除咔哒声和爆音，写死在 lib
- 不区分旋律与伴奏的统一 AGC、钢琴波表、共振峰、软限幅均已试，在该蜂鸣器上沙沙声重或音量太小，不采用
- `Melody::monitor` 统计合成中断频率与占用

## 转换

```sh
python tools/midi_to_song.py [MIDI 路径]
```

依赖 `mido`，试听用 `winsound`，仅 Windows。脚本列出各音轨的音符数、音域、最多同时发声数，并按音轨名、重复配器、音高给出建议分组：

| 命令 | 作用 |
| --- | --- |
| `m/c/x 序号...` | 设为旋律 / 伴奏 / 不用 |
| `p 序号` | 试听单个音轨 |
| `p` / `pm` | 试听复音模式 / 普通模式 |
| `t 秒` | 试听起点，每次 20 s |
| 回车 | 确认分组，输入输出目录（默认 `lib/melody/music`）与曲目名 |

试听是电脑近似合成，只用于确认音轨内容；蜂鸣器只在 2.5–4.5 kHz 有效发声，音量与音色以板上为准。

## 规则

1. 合并同组音轨，按 tempo 变化换算时间；打击乐通道 10 不转换；同一 tick 先松开再按下
2. 主声部：空闲时按下即占用，更高（伴奏为更低）的音抢占，松开即休止不回退
3. 内声部：其余按下的音及被抢占的音放入编号最小的空声部，无空声部时新增；每组最多 8 个声部
4. 伴奏低于 C3 的音按八度升高
5. 切换时刻对齐到 10 ms 网格，误差不累积；全曲首音对齐到 0
6. 同音重击之间无休止时从前一个音借 10 ms 作休止
7. 超过 2550 ms 的条目拆成多个同音条目，连续发声
