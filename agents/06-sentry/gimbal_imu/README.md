# GimbalFold 大小 yaw 世界系反馈与本地窗口

状态：2026-11-28 按用户决定接入上游 yaw1/yaw2 控制，保留本地 ±50° 自瞄窗口与 pitch2 控制；本轮验证结果见 `../upstream/README.md`

## 当前控制

`lib/robot/gimbal_fold.*` 接收 `update(q, gyro)`，q 为云台到世界的姿态，gyro 为安装修正后的机体系角速度。目标与观测、PID 配置使用上游接口名；pitch2 保留本地计算逻辑和增益。

| 轴 | 外环反馈 | 内环反馈 | 输出 |
| --- | --- | --- | --- |
| 小 yaw | 头部 IMU 世界航向 | `(q * gyro).z()`，头部角速度的世界 Z 分量 | 电流，A |
| 大 yaw | 头部 IMU 航向减小 yaw 编码器角 | 世界 Z 角速度减小 yaw 编码器速度 | 力矩，N·m |
| pitch2 | 世界目标换算后的编码器角 | pitch2 电机编码器速度 | 力矩，N·m，叠加原重力补偿 |

- 删除 ECD 模式与 `set_chassis_wr()`，底盘旋转进入 yaw 的 IMU 反馈；大小 yaw 必须同时在线，否则清目标与 PID、两轴输出零，恢复首周期初始化
- 大小 yaw 平面分解按关节轴近似世界竖直处理；pitch2 正常抬俯不改变该分解，底盘倾斜或横滚时需另行校核反馈误差
- 大小 yaw 增益按上游保持零，当前为待整定状态；yaw 位置环可选平方根减速规划默认 `INFINITY`，不启用
- pitch1 全程固定失能，保留反馈和失能帧

## 小 yaw 优先窗口

- 保留 `set_yaw_window()`：允许交战且当前识别到目标时启用；过洞断联期间不刷新这一输入
- 进入窗口保存大轴实测世界朝向。头部目标在该朝向的 ±50° 内时大轴保持、小轴跟踪；越界时大轴补足越界角度
- 退出窗口后大轴持续跟随头部世界目标，小轴在大轴追上后回中；失能或 yaw 掉线后窗口状态重新初始化
- 小 yaw 实测到达 ±50° 时截断朝外输出并回算积分，保留向内回程
- 窗口内目标转速由小轴承担，大轴不叠加头部目标转速；底盘自转由大轴世界速度反馈抑制

## pitch2 保留项

- 目标经 `IMU pitch - 编码器 pitch` 偏差换算为编码器角，再钳制到 −0.1～0.314 rad；扫描端点与此范围一致
- 位置环用编码器目标误差，速度环用电机编码器速度；目标被钳制时撤掉 `pitch_speed` 前馈
- 速度 PID 保持 `kp=0.50558, ki=2, kd=0.02, ff=-1.55, max_i=0.4, max_out=5, err_fc=10`；位置 PID 保持 `kp=20, max_out=720°/s`
- 重力补偿继续按 `torque * cos(IMU pitch + phase)` 计算，PID 跟踪电机限幅后扣除重力补偿的实际输出；当前补偿配置为零
- 不引入上游 pitch2 的 `gyro.y()` 内环、编码器边界输出截断或 pitch 加速度规划

## IMU 配置

- 上游传感器系零偏 XYZ：`(0.00412, 0.00166, 0.00212)` rad/s
- 重力标定值：`9.80907 m/s²`
- 安装 yaw/pitch/roll：−90°/0°/180°；目标温度使用默认 45 ℃
