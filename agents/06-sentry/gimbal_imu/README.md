## 当前控制

`lib/robot/gimbal_fold.*` 接收 `update(q, gyro)`，q 为云台到世界的姿态，gyro 为安装修正后的机体系角速度。目标与观测、PID 配置使用上游接口名；pitch2 保留本地编码器串级、限位处理和增益。

| 轴 | 外环反馈 | 内环反馈 | 输出 |
| --- | --- | --- | --- |
| 小 yaw | 头部 IMU 世界航向 | `(q * gyro).z()` 经一阶低通后的世界 Z 角速度 | 电流，A |
| 大 yaw | 头部 IMU 航向减小 yaw 编码器角 | 滤波后的世界 Z 角速度减小 yaw 编码器速度 | 力矩，N·m |
| pitch2 | 世界目标换算后的编码器角 | `motor.pitch2.speed`，电机编码器速度 | 力矩，N·m，叠加原重力补偿 |

- 删除 ECD 模式与 `set_chassis_wr()`，底盘旋转进入 yaw 的 IMU 反馈；大小 yaw 必须同时在线，否则清目标与 PID、两轴输出零，恢复首周期初始化
- 大小 yaw 平面分解按关节轴近似世界竖直处理；pitch2 正常抬俯不改变该分解，底盘倾斜或横滚时需另行校核反馈误差

## IMU yaw 速度滤波

- `app/jelly_sentry/gimbal.hpp` 的 `.yaw_gyro_fc = 50.0f` 设置一阶 RC 低通截止频率，Hz；非负，0 直通。滤波在世界 Z 轴投影后执行，使用 `update()` 的实际限幅周期和公共 `lowpass()`
- `yaw.speed_measure` 保存滤波输出，大小 yaw 共享；大轴继续扣除未滤波的小 yaw 编码器速度。失能、任一 yaw 离线或恢复首周期直接同步当前 IMU 测量，避免旧状态带入

## 小 yaw 优先窗口

- `set_yaw_window()` 跟随锁定：锁定中（含脱锁后 500 ms 保持）启用，扫描时关闭，由大 yaw 叠加转速前馈承担扫描；回家途中不进入锁定
- 进入窗口保存大轴实测世界朝向。头部目标在该朝向的 ±50° 内时大轴保持、小轴跟踪；越界时大轴补足越界角度
- 退出窗口后大轴持续跟随头部世界目标，小轴在大轴追上后回中；失能或 yaw 掉线后窗口状态重新初始化
- 小 yaw 实测到达 ±50° 时截断朝外输出并回算积分，保留向内回程
- 窗口内目标转速由小轴承担，大轴不叠加头部目标转速；底盘自转由大轴世界速度反馈抑制
