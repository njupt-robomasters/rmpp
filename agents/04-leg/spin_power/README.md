# 19 轮腿小陀螺功率限幅

状态：历史实验；限幅逻辑已被 `24-leg_power_alloc` 取代，遗留结论仍适用

历史实验：本目录的限幅测试针对旧接口。实验源码归档于提交 `3b24d74`，该提交的 `calc_lqr()` 已旁路限幅；复现以下限幅结果需恢复记录中的限幅调用。当前轮腿直接使用 LQR 输出。

## 现象

`logs/emberprobe-live-20261121-102711.csv`：02:26:41.5–42.8，`chassis.power.gain` 在约 250 ms 内从 1 掉到 0.312 → 0.019 → 0，保持 0 约 1 s 后自行恢复；期间 `power_ref` 稳定在 395–405 W，`chassis.power.estimate` 只有 85–160 W。42.338 s `is_fallen`、`rescue` 置位，进自救。

## 日志结论

- 41.5 s 转向目标 `d_yaw_ref` 从 15.5 阶跃到 17.9 rad/s，陀螺航向角速度停在 14.4，误差项从 1.15 涨到 3.4，右轮 drive 力矩 2.0 → 4.4 N·m。轮速 54–56 rad/s（输出轴 ≈ 8870 rpm，接近 M3508 空载转速），这个转向速度在 0.244 m 半径下对应 4.2–4.9 m/s，超出轮速能力（实测 3.3 m/s）。
- 同一时段右腿后摆，theta 误差到 0.25 rad、`d_theta` 到 1.8 rad/s，右轮 balance 力矩 0.27 → 6.0 N·m。逐项分解（41.784 s）：theta 项 4.28、`d_theta` 项 0.94、`-d_pitch` 项 1.18。
- 用日志状态和 LQR 拟合系数复算 `limit_power`，得到的 gain 与日志一致。41.784 s：a=33、b=422、c=+43，二次式在 g≥0 恒正，`solve_gain` 返回 0。c 中右轮 balance 单项功率 6.0 × 55.2 = 331 W，占 399 W 预算的 83%。
- gain 归零后 drive 全切，航向误差和腿摆继续变大，balance 力矩涨到 20.9 N·m，c 涨到 1560 W，限幅器锁死在 0，直到倒地进自救才解除。

## 模型偏差

- `limit_power` 用 balance、drive 原值建模，未按电机 `max_torque`（5.09 N·m）限幅；`Tw` 日志到 20.9 N·m 时，实际下发已被 `Motor::set_torque` 截到 5.09。
- 高速段电机电压受限：指令力矩 2.2 → 6.1 N·m 时实测功率只从 63 W 涨到 120 W，反推力矩约 1–1.5 N·m。模型按指令力矩乘实测轮速计算，同帧预测 442 W、实测 85 W，差 5 倍。

## 修改

`lib/robot/chassis_leg.cpp` `limit_power()`：

- A 输入限幅：balance、drive 先按各轮 `max_torque` 限幅，再进入功率二次式；`Tw` 合成后同样限幅，日志值与实际下发一致。
- B 防止自锁：drive 的 gain 解为 0 时，再按同一规则求平衡力矩的衰减系数 `balance_gain`，`Tw = balance_gain·(平衡 + gain·驱动)`。`power_ref` 为 0 表示未设置，此时保持平衡力矩（沿用原语义）；`power_ref` 为无穷大时不进该分支。

文档同步：`agents/02-conventions/application.md` 轮腿功率控制一节、`chassis_leg.hpp` 接口注释。

## 遗留

- 转向指令 `wr` 未限幅。17–20 rad/s 需要 4.2–4.9 m/s 轮速，车只能到 3.3 m/s，航向误差长期饱和，任何增益都会把预算打满。建议限到约 13 rad/s 并加斜坡。
- 高速段模型仍按指令力矩计算，实测只有其 1/5。若继续出现误限，需要按可达力矩或实测功率做修正。
- B 触发时平衡力矩会被衰减，倒地风险上升，需上车确认是否接受。

## 上车核对（架空或低速）

1. 正常平衡与小陀螺时 `chassis.power.gain` 不掉到 0，`power.estimate` 稳定在 `power_ref` 以下。
2. 空载缓慢停转时 `leg[].Tw` 不超过 5.09 N·m，日志与电机实际电流一致。
3. 断开超电或裁判（`power_ref` 为 0）时轮端保持平衡力矩。
4. 小陀螺叠加转向到底时观察是否出现平衡力矩衰减，以及姿态是否可控。
