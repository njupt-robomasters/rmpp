# 17 mm 小球引起单腿抽动：摆腿保护调研

**状态：仅调研，未实施，未做仿真或上车验证。** 队员观察到，车轮踩球后，一条腿会猛地抽动，随后轮子短时空转，车身可能前后发颤。可以接受正常行驶中的轻微打滑；主要目标是压住单腿突然后摆及随后的俯仰振荡，同时保留起步响应和急刹能力。

## 推荐方案

优先验证一条规则：**一条腿已经摆得很快、两腿摆动明显不一致、前向速度控制仍在顺势推这条腿时，只削弱该腿同向的追速摆矩。** 不进行通用打滑识别，不等轮子空转才介入，也不新增卡尔曼滤波。

| 本拍看什么 | 如何判断 |
| --- | --- |
| 这条腿是否摆得快 | 用腿相对车身的摆角速度：左 `-leg[0].d_phi0`，右 `+leg[1].d_phi0`，单位 rad/s，后摆为正。它由关节速度经五连杆运动学得到，无需对相邻两拍角度作差。`d_theta` 还包含车身俯仰角速度，留给平衡反馈。 |
| 是否为单侧异常 | 同时看本腿摆速幅值和左右**有符号**摆速之差的幅值。两腿同向同速时差接近零；若只比较两个速率的绝对值，会漏掉两腿等速反摆。阈值留待本车日志确定。 |
| 控制器在推腿还是收腿 | 分配前的总摆矩、其中由 `vx - body.d_x` 产生的摆矩分量，均与本腿摆速同号时才介入。总摆矩已在制动，或车速项正在帮忙制动，均保持原输出。 |

仅在正常平衡行驶时判断；跳跃、自救不参与。越过阈值后平滑削弱该腿的同向车速项，摆速和左右差回落时平滑恢复，不锁存模式。保留腿角、俯仰反馈和腿长支撑，不直接减半轮电流。调整放在现有额定力矩与功率分配之前，沿用姿态优先和原输出限幅。

## 为什么要区分起步、急刹

起步第一拍只有速度指令变化，腿还没摆快。随后为加速而主动调整姿态时，可能出现“腿已快速后摆，车速项继续往后推”。急刹同理：车在减速，腿可能正被主动往前摆；**刹车时仍可能在加速摆腿**。仅用单腿摆速和推力方向，两种正常动作都可能触发。

直线起步、急刹时两腿通常协同摆动，用左右差放行这部分动作。带转向急刹、单侧颠簸时两腿也可能不同步，仍有误触发风险；后果是短时少给一侧追速摆矩，可能使反向响应变慢或制动距离变长。两腿同步踩球时则可能漏判。这是首版为保护正常操控保留的边界。

## 方案依据

**本车源码与待证因果。** `lib/robot/chassis_leg.cpp:142` 从关节速度求腿长变化率和摆角速度；`lib/robot/chassis_leg.cpp:167` 把各侧轮速与腿摆补偿相加，再取均值作为 `body.d_x`；`lib/robot/chassis_leg.cpp:407` 把前向速度误差送入两轮和两腿的 LQR 输出。因此，踩球时轮速或腿摆突变，**可能**通过车速反馈再推一次腿。是否实际放大了后摆，要看抽动时车速项与最终摆矩的方向。

## 今后如何验证

1. **先观察，不接管。** 对齐控制拍与视频，记录左右相对摆速、`rel_theta`、`d_L`、轮速、`vx` 与 `body.d_x`、各腿分配前的车速项摆矩和总摆矩、分配后的 `Tt`、车身俯仰角及角速度。`Tt` 是下发的虚拟摆矩指令，不是地面对腿的实测力矩。
2. **先判原因，再选阈值。** 左轮、右轮分别踩球，对照无球直线猛起步、急刹、急反向、带转向急刹及普通轻滑。若踩球后 `d_L` 先突变而摆速平稳，优先查腿长支撑环；若后摆时最终摆矩一直反向制动，优先查接触冲击；若追速分量和最终摆矩持续同向助推，才继续评估该保护。看不同腿长和功率预算下正常工况与踩球的左右摆速差能否分开，存在明显重叠时保留为观测，不硬定阈值。
3. **验收看姿态和操控。** 踩球对比最大后摆角、俯仰峰值、振荡次数及恢复时间；无球对比误触发次数、实际起步和反向速度响应、相同初速下的制动距离。轮子空转峰值仅作事件佐证。
