# 02 约定与项目结构

状态：规则已稳定；全局重构已并入 master

根 `AGENTS.md` 是赛事语境、沟通方式和通用代码约定的总入口；本主题存细节和项目结构说明。

## 文档

| 文件 | 内容 |
| --- | --- |
| `conventions.md` | 编码、命名、类成员与函数布局、注释与格式；含具体类特例 |
| `workflow.md` | 并行修改边界、验证与交付、约定维护 |
| `verification.md` | 验证分层、常用命令、人工审计入口、板上注意事项 |
| `architecture.md` | 目录与接口、启动与句柄、板卡资源、构建与格式化 |
| `application.md` | app 职责边界、启动与循环、文件组织、遥控映射、GimbalClassic、哨兵、超电、轮腿上下板通信 |

## 任务记录

- `global_refactor/`：全局代码优化与类布局重构，含 Timer/PID dt、电机配置与符号、成员六组与函数排序、最小权限；脚本可复现电机与超电回归

## 维护

- 赛事语境、沟通方式和通用代码约定写根 `AGENTS.md`；详细说明和类特例写 `conventions.md`
- 协作、验证和交付细则写 `workflow.md`
- 仅特定模块适用的规则写对应主题目录，并同步该主题 README 的索引
- 更新前读现有条目，修改原规则，不重复追加
