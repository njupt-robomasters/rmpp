## 已做实测

- 通过 mcu-variables 技能读取和有限采样，固件 ELF SHA-256 为 `b3683db81e128124098141b92570d3ef8702f3d3e18f985366705df1d9ed8a65`，Ember 记录匹配
- 初始小轴约 −35°，实际运行软件限位 ±40°；先采用向中位方向的 2° 小阶跃，随后按用户要求扩大至 20°
- 在低输出上限下，小轴速度环原值 kp=0.5729578、ki=0.2864789 有明显低速迟滞；临时试验至 kp=2.2918313、ki=1.1459156，位置环 kp=10，D 保持 0
- 小轴 20° 测试：位置环限速 30°/s、限流 2 A，记录中的实际运动约 20.66°、峰值反馈速度 32°/s、指令电流峰值 0.942 A；从第一条采样起约 2.95 s 后持续进入头部 ±0.4° 误差带
- 大轴原增益 kp=1.1459156、ki=0.5729578，位置环 kp=5，限矩 1.5 N·m、限速 30°/s；世界参考反向 20° 后，6.61 s 记录结束时约有 1.04° 误差，小轴补偿头部
- 初期单次写入与采样分开进行，命令落地到第一条样本之间的时间未精确测得，上述响应时间按记录起点计算。正弦需要板上定时生成，主机多次写入与长采样会排队
- 后续条件检查发现头部目标、底盘转速改变，拦截了计划中的大轴加倍参数测试；最终只读确认增益和输出上限均已恢复生产原值，pitch1 失能且 current_ref/torque_ref 为 0
- 原始记录在 `agents/out/25-yaw_pid/session.json`，属临时数据；本次试验值尚未作为最终整定参数写入生产配置
