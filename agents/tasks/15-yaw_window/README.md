## 实现

- 最终头部世界航向目标继续使用 yaw.imu.ref；大轴保存独立的世界参考 yaw1_world_ref，避免末尾用大轴目标覆盖头部目标
- 头部目标相对大轴实际世界朝向超过45°触发追随，回到35°以内停止追随，回差区保持状态；生产小轴软件限位40°，测试夹具采用45°
- 2026-11-21 用户要求大轴提速：移除4/s参考轨迹减速增益、180°/s轨迹限速和720°/s²轨迹限加速度；追随时直接给出头部目标减同向35°的世界参考，使用现有位置环720°/s输出上限。停止追随时保存实际世界朝向；追随速度前馈使用头部目标速度，保持期间为零，底盘旋转补偿继续叠加
- 大轴世界测量为 imu_yaw - 小yaw相对角；大轴相对速度前馈减底盘转速，小轴减去底盘与大轴实测相对转速之和，承担剩余头部误差
- 两轴在线的 IMU_MODE 启用窗口；离线/ECD 清窗口状态，双轴恢复后从当前世界测量初始化。小轴离线时大轴利用保持的小轴测量承担头部误差；离线轴清 PID 和输出零
- pitch1 全程失能、测量保持及失能帧发送保持现有策略；俯仰和自瞄/导航协议未变
- 模型按两 yaw 轴平行、仅位置偏置处理；偏心引起的目标视差需视觉外参和距离补偿
