# 09 轮腿 LQR 复现与定位分析

## 目标

用 Python 复现 `SOLDIER_LEG_4/Leg_Lqr__4.m`（上交 2023 轮腿模型，方程 3.11–3.15），分析云台朝后时底盘持续漂移、原地定位软的原因

## 复现

- `lqr_model.py`：方程对加速度、角度、力矩线性，numpy 直接组装 A、B，`scipy` 求 Riccati，不需要 MATLAB/sympy；另给机体重心水平偏移 d 的扰动列 E
- `gen_lqr_fit.py`：按 `lqr_model.py` 顶部的机体参数与 Q、R 生成 `app/leg_down/lqr_fit.hpp`（输出已与 clang-format 一致）；改参数后重跑即可替换
- `offset_analysis.py`：按本工程实际用法（C 拟合增益、`x_max`）求稳态

```sh
python gen_lqr_fit.py
python lqr_model.py ../../../app/leg_down/lqr_fit.hpp
python offset_analysis.py ../../../app/leg_down/lqr_fit.hpp
```

## 结论

- 复现结构正确：K 的符号、左右对称、量级与 C 系数一致；本脚本自己做 poly22 拟合误差 < 0.3%
- 原 `chassis.hpp` 中的 LQR_FIT（fe6ed67 及之前）不是 `.m` 当前参数生成的：L = 0.18 时最大差 8.8%，位移、速度两列差约 60%（-1.04 vs -0.64）；改 Q、R 搜索也对不上，v2 参数、v2 列序等组合也对不上（最好 8%），来源不明；已换成 v4 参数的 Python 生成版，位移、速度增益比原来约小 40%，定位会更软
- 模型参数可疑：`I_ll = 0.0525 kg·m²` 对 1.2 kg 的腿偏大一个量级；v2 文件 `l_bl` 与 `I_ll` 两列放反；模型总质量 21.5 kg，C 配置 22.75 kg
- 漂移机理：重心水平偏移 d 时，静止平衡要求腿倾斜（约 -3°/cm）让重心回到轮轴上方。腿角误差产生的轮力矩只能靠位移项抵消，所以纯 LQR 必有位移稳态误差 s = K_θ·Δθ / K_s；位移再被 `x_max` 限幅后，剩下的只能靠速度误差抵消 → 恒速漂移
- 当前（×10）：每 1 cm 偏移稳态 10.2 cm；`x_max = 0.1 m` 只能抵抗约 1 cm 偏移，2 cm 时漂移约 42 cm/s。加大倍数只缩小偏差、不消除，且受 `x_max` 封顶
- LQI（增广 ∫s 状态）：Q_s = 2000、Q_∫s = 500 时 2 cm 偏移稳态位移为 0，闭环仍稳定（最慢极点约 -0.5）
- 旧车（原系数、位移误差 ×10、`x_max = 0.1`）：最慢闭环极点约 -0.4 ± 1.9j，ζ ≈ 0.2，定位慢且来回晃；×10 只放大位置增益而速度增益不变，是欠阻尼来源
- 纯比例位移有物理上限：Q_s = 2e5 时 1 cm 偏移仍需 4.7 cm 回位位移；要更小只能靠积分（LQI）

## 当前调参（Q_s 调硬，不加 ∫s）

- C 代码删去位移误差 ×10 与 `x_err_max`，位移刚度全部由 Q_s 给出，K 与模型一致
- Q_s 60 → 50000，其余 Q、R 不变；L = 0.18 时 K_s ≈ -17.3、K_v ≈ -11.9（旧车 -10.4、-2.6）
- 最慢极点 -2.0 ± 1.6j，ζ ≈ 0.78；1 cm 重心偏移稳态位移 7.2 cm
- `x_max` 0.1 → 0.3 m：可抵抗约 4.2 cm 重心偏移不漂移（0.1 时仅约 1.4 cm）；30 cm 位移对应单轮约 5.2 N·m，接近 M3508 轮端上限 5.1 N·m
- 腿长 0.11–0.30 m（含左右不等长极端）拟合 K 闭环全部稳定，最大实部 ≤ -1.7；2 ms 周期加 4 拍输入延迟仍稳定；m_b +20%、l_c 0–2 倍、I_b 2 倍下仍稳定
- 风险：K_v 约为旧车 4.6 倍，摇杆速度阶跃时轮力矩更大、易饱和并带动俯仰，必要时给速度指令加斜坡
