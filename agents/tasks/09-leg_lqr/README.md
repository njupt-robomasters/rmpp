# 09 轮腿 LQR 复现与定位分析

## 目标

用 Python 复现 `SOLDIER_LEG_4/Leg_Lqr__4.m`（上交 2023 轮腿模型，方程 3.11–3.15），分析云台朝后时底盘持续漂移、原地定位软的原因

## 复现

- `lqr_model.py`：方程对加速度、角度、力矩线性，numpy 直接组装 A、B，`scipy` 求 Riccati，不需要 MATLAB/sympy；另给机体重心水平偏移 d 的扰动列 E
- `offset_analysis.py`：按本工程实际用法（C 拟合增益、位移误差 ×10、`x_max = 0.1 m`）求稳态

```sh
python lqr_model.py ../../../app/leg_down/chassis.hpp
python offset_analysis.py ../../../app/leg_down/chassis.hpp
```

## 结论

- 复现结构正确：K 的符号、左右对称、量级与 C 系数一致；本脚本自己做 poly22 拟合误差 < 0.3%
- 但 `app/leg_down/chassis.hpp` 的 LQR_FIT 不是 `.m` 当前参数生成的：L = 0.18 时最大差 8.8%，位移、速度两列差约 60%（-1.04 vs -0.64）；改 Q、R 搜索也对不上，推测生成时用了别的机体参数
- 模型参数可疑：`I_ll = 0.0525 kg·m²` 对 1.2 kg 的腿偏大一个量级；v2 文件 `l_bl` 与 `I_ll` 两列放反；模型总质量 21.5 kg，C 配置 22.75 kg
- 漂移机理：重心水平偏移 d 时，静止平衡要求腿倾斜（约 -3°/cm）让重心回到轮轴上方。腿角误差产生的轮力矩只能靠位移项抵消，所以纯 LQR 必有位移稳态误差 s = K_θ·Δθ / K_s；位移再被 `x_max` 限幅后，剩下的只能靠速度误差抵消 → 恒速漂移
- 当前（×10）：每 1 cm 偏移稳态 10.2 cm；`x_max = 0.1 m` 只能抵抗约 1 cm 偏移，2 cm 时漂移约 42 cm/s。加大倍数只缩小偏差、不消除，且受 `x_max` 封顶
- LQI（增广 ∫s 状态）：Q_s = 2000、Q_∫s = 500 时 2 cm 偏移稳态位移为 0，闭环仍稳定（最慢极点约 -0.5）
- 当前最慢闭环极点约 -0.4 ± 1.9j（C 增益 ×10），定位慢且欠阻尼
