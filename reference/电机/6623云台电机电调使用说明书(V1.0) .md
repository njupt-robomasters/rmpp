## 简介

RM 6623 电调采用高性能 32 bit MCU，结合磁场定向控制（FOC）技术，搭配 RM 6623 无刷电机，专为 ROBOMASTERS™ 机器人战车云台打造。

电机与电调采用一体化设计，并整合高精度绝对式编码器，以提高位置反馈与力矩输出的精度。

## 部件和接口

### 拨码开关

- 第 1 位：选择是否接入 CAN 总线的 120 Ω 终端电阻
- 第 2、3、4 位：设置设备 ID

### CAN 总线通信及电源接口

电调具有两个 CAN 总线通信及电源接口。使用 8 Pin 线连接 ROBOMASTERS 战车云台主控，或其他任意一款云台电机的 CAN 端口。

CAN 通信数据线各线缆定义如下：

| 颜色 | 定义 | 说明 |
| --- | --- | --- |
| 红色 | 电源正极 | 宽电压供电，范围为 15～26 V |
| 黑色 | 电源负极 | - |
| 黄色 | CANH | CAN 总线高电平信号线 |
| 灰色 | CANL | CAN 总线低电平信号线 |

根据协议规范，CAN 总线上需要接入两个 120 Ω 终端电阻。更多信息参见《6623 无刷电机使用说明》[^motor-manual]。

### 电机及霍尔端口

该端口为 14 Pin，包含电机三相电源线、电机霍尔供电线和霍尔信号线。该端口连接至 RM 6623 无刷电机对应的 14 Pin 霍尔端口。

### LED 指示灯

LED 用于指示驱动板的设备 ID 或运行状态。正常运行时绿色 LED 闪烁，具体闪烁次数参见[拨码开关设置](#拨码开关设置)。

## 安装连线

1. 移除 RM 6623 无刷电机上的螺丝和电机盖。
2. 使用霍尔连接线连接电机与电调的霍尔端口。
3. 使用 CAN 信号线连接主控板的 CAN 接口与电调的 CAN 总线通信及电源接口。

## 使用电调

1. 完成安装连线后，通过拨码开关设置设备 ID。电调上的绿色 LED 会通过闪烁提示当前设备 ID。
2. 通过带 CAN 接口的 MCU 或其他控制器，发送符合电调通信协议的 CAN 报文，以控制电机转动。

## 拨码开关设置

### 设备 ID

拨码开关第 2、3、4 位分别简称 B2、B3、B4，对应 ID 的 bit 2～bit 0：

- B2 为最高位（MSB），B4 为最低位（LSB）
- 开关在下方表示 `0`，在上方表示 `1`
- B2、B3、B4 组成的三位二进制数记为 `x`，范围为 `0b000`～`0b111`，即十进制 `0`～`7`
- 电调反馈报文的 CAN ID 为 `0x205 + x`
- LED 每 1.5 s 快速闪烁 `x + 1` 次

例如，B2、B3、B4 为 `001` 时，`x = 1`，驱动板类型为 Pitch，反馈报文 ID 为 `0x206`，LED 每 1.5 s 快速闪烁 2 次。

| B2B3B4 | x | 驱动板类型 | 反馈报文 ID |
| --- | ---: | --- | --- |
| `000` | 0 | Yaw | `0x205` |
| `001` | 1 | Pitch | `0x206` |
| `010` | 2 | Roll | `0x207` |
| `011` | 3 | Resv | `0x208` |
| `100` | 4 | Ex1 | `0x209` |
| `101` | 5 | Ex2 | `0x20A` |
| `110` | 6 | Ex3 | `0x20B` |
| `111` | 7 | Ex4 | `0x20C` |

### CAN 终端电阻

拨码开关第 1 位控制 CAN 总线终端电阻。拨到 `ON` 时，接入 120 Ω 终端电阻。

## 通信协议

RM 6623 电调使用 CAN 总线通信。在通常的 Pitch、Yaw 两轴云台结构中：

- Yaw 轴反馈报文 ID 为 `0x205`
- Pitch 轴反馈报文 ID 为 `0x206`
- 新增的 Roll 轴反馈报文 ID 为 `0x207`
- `0x208`～`0x20C` 为预留或扩展驱动板 ID

电调内部集成电流环控制，并实时输出电机运行状态。用户可根据云台控制需求，在主控中实现速度环和位置环，将控制器输出量填入 CAN 数据帧对应的位域，并作为转矩命令发送给驱动板。驱动板接口使用方法参见《RM 6623 无刷电机使用说明》[^motor-manual]。

### 电调接收：校准命令

电机在出厂时已经校准。更换电机或电调板后，需要重新校准电机。

安装好电机和电调后，在不带负载的情况下，通过 CAN 向电调板发送下列数据。电机将自动进入校准流程：供电电流约为 2 A，电机堵转约 6 s 后完成校准。

| 属性 | 值 |
| --- | --- |
| 标识符 ID | `0x3F0` |
| 帧类型 | 标准帧 |
| 帧格式 | DATA |
| DLC | 8 字节 |

| 数据域 | 内容 |
| --- | --- |
| `DATA[0]` | 字符 `'c'` |
| `DATA[1]`～`DATA[7]` | `0xXX`，任意值 |

当标识符 ID 为 `0x3F0` 且 `DATA[0] == 'c'` 时，电机进入校准模式。

校准注意事项：

- 仅更换电机时需要校准
- 建议在空载情况下校准电机
- 如果多次校准后电机仍不正常，建议更换电机

| Ex2 | `0x20A` |

通用帧属性：

| 属性 | 值 |
| --- | --- |
| 帧类型 | 标准帧 |
| 帧格式 | DATA |
| DLC | 8 字节 |
| 发送频率 | 1 kHz |

| 数据域 | 内容 |
| --- | --- |
| `DATA[0]` | 机械角度高 8 位 |
| `DATA[1]` | 机械角度低 8 位 |
| `DATA[2]` | 实际转矩电流测量值高 8 位 |
| `DATA[3]` | 实际转矩电流测量值低 8 位 |

| `DATA[5]` | 转矩电流给定值低 8 位 |

| `DATA[7]` | Null |

数据范围：

- 机械角度值：0～8191（`0x1FFF`）
- 实际电流测量值：-13000～13000
