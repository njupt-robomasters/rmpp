# RoboMaster C610 无刷电机调速器使用说明

> 根据《RM C610 无刷电机调速器使用说明 发布版》（2018.01，V1.0）整理。为便于检索和编写控制代码，省略免责声明、图片和性能曲线，保留接口、配置、通信协议及规格信息。若本文与原 PDF 有歧义，以原 PDF 为准。

## 产品概述

C610 使用 FOC 控制，与 RoboMaster M2006 直流无刷减速电机配套使用。

- 控制方式：CAN 总线
- 最大持续电流：10 A
- 支持为同一 CAN 总线上的电调快速设置 ID
- 可通过 CAN 获取转子位置和转速
- 额定供电电压：DC 24 V

## 使用注意事项

- 接线前确认电路无短路、接口连接正确
- 大功率输出时电调会发热，注意防止烫伤
- 使用前检查热缩管是否完好
- 不可同时连接串口调参端口和 CAN 通信端口；切换端口前先断电
- 初次使用、更换电机或更换电调后必须执行电机校准

## 接口与接线

1. **电源线**：连接额定 24 V 电源
2. **三相动力接头**：连接 M2006 三相动力接头，不可接错
3. **4-Pin 位置传感器端口**：连接 M2006 位置传感器数据线
4. **固定槽**：两个对称固定槽，建议使用 M2 螺丝
5. **SET 按键**：设置 ID 和执行电机校准
6. **指示灯**：显示工作、警告和异常状态
7. **CAN 终端电阻开关**：`ON` 接入 120 Ω，`NC` 断开 120 Ω
8. **CAN 信号线**：比特率 1 Mbps
9. **串口调参端口**：连接 3.3 V USB 转串口工具，用于 RoboMaster Assistant 调参和升级

### 线序

| 接口 | 从上到下的线序 |
| --- | --- |
| CAN | 红色 `CAN_H`、黑色 `CAN_L` |
| 串口调参 | `RXD`、`TXD`、`GND` |

安装时依次连接 4-Pin 位置传感器线、三相动力线、CAN 线和电源线。CAN 总线两端按总线规范接入终端电阻。

## SET 按键操作

### 单独设置 ID

ID 范围为 1～8。

1. 正常工作时短按一次 SET，进入单独设置模式，指示灯熄灭
2. 再短按 SET，按键次数即为 ID；最多按 8 次，每次有效按键橙灯闪一次
3. 停止操作 3 秒后自动保存，重新上电后生效

同一 CAN 总线上不得有重复 ID，否则冲突电调会告警并关闭输出。

### 快速设置 ID

一条总线最多为 8 个 C610 快速编号。

1. 短按任意一个电调的 SET 进入单独设置模式，再长按 SET
2. 所有电调橙灯常亮，进入快速设置模式
3. 按期望的 ID 顺序，依次手动将相应 M2006 转子向任意方向旋转至少半圈
4. 电调按转动顺序自动分配 ID 1、2、3……；重新上电后生效

未转动的电机保持原 ID。

### 电机校准

1. 电机和电调正确连接并上电
2. 长按 SET，直到绿灯快闪后松开
3. 电机自动校准，完成后自动退出

校准期间电机会转动，应空载操作且不要触碰。多次校准失败时更换电机。

## CAN 通信协议

### 基本参数

- CAN 比特率：1 Mbps
- 帧类型：标准帧
- 帧格式：数据帧
- DLC：8 字节
- 所有 16 位值均为高字节在前、低字节在后

### 控制报文

控制量为 16 位有符号转矩电流给定值：

- 数值范围：-10000～10000
- 对应电调转矩电流：-10～10 A
- 换算：`current_A = command / 1000`

#### ID 1～4

- 标识符：`0x200`

| 字节 | 内容 |
| --- | --- |
| `DATA[0:1]` | ID 1 控制电流，高 8 位在前 |
| `DATA[2:3]` | ID 2 控制电流，高 8 位在前 |
| `DATA[4:5]` | ID 3 控制电流，高 8 位在前 |
| `DATA[6:7]` | ID 4 控制电流，高 8 位在前 |

#### ID 5～8

- 标识符：`0x1FF`

| 字节 | 内容 |
| --- | --- |
| `DATA[0:1]` | ID 5 控制电流，高 8 位在前 |
| `DATA[2:3]` | ID 6 控制电流，高 8 位在前 |
| `DATA[4:5]` | ID 7 控制电流，高 8 位在前 |
| `DATA[6:7]` | ID 8 控制电流，高 8 位在前 |

### 反馈报文

- 标识符：`0x200 + 电调 ID`，例如 ID 1 使用 `0x201`
- 默认发送频率：1 kHz，可在 RoboMaster Assistant 中修改

| 字节 | 内容 | 类型或单位 |
| --- | --- | --- |
| `DATA[0:1]` | 转子机械角度 | 0～8191 对应 0～360° |
| `DATA[2:3]` | 转子转速 | rpm |
| `DATA[4:5]` | 实际输出转矩 | 原始 16 位反馈值 |
| `DATA[6]` | 未使用 | `Null` |
| `DATA[7]` | 未使用 | `Null` |

## 指示灯与鸣音

异常状态下电调关闭输出。多个警告或异常同时存在时，显示闪烁次数最少的状态；异常优先于警告。

| 类别 | 指示 | 含义 |
| --- | --- | --- |
| 正常 | 绿灯每秒闪 N 次 | 当前 ID 为 N，N 为 1～8 |
| 快速设置 ID | 橙灯常亮 | 正在快速设置 ID |
| 校准 | 绿灯快闪 | 正在校准电机 |
| 警告 | 橙灯每秒闪 2 次 | CAN 总线上存在重复 ID |
| 异常 | 红灯每秒闪 1 次 | 供电电压过高，仅开机自检 |
| 异常 | 红灯每秒闪 2 次 | 三相线未接入 |
| 异常 | 红灯每秒闪 3 次 | 4-Pin 位置传感器信号丢失 |
| 异常 | 红灯快闪 | 电机校准失败 |

| 鸣音 | 含义 |
| --- | --- |
| 开机音 | 系统就绪 |
| `BB--BB--BB……` | 电机堵转 |
| `BBB--BBB--BBB……` | 4-Pin 位置传感器信号丢失 |

## RoboMaster Assistant

- USB 转串口电平必须为 3.3 V
- 电调 `GND`、`TXD`、`RXD` 分别连接转换器对应的地、接收和发送端；收发线应交叉连接
- 调参或升级完成前不要断电或断开连接
