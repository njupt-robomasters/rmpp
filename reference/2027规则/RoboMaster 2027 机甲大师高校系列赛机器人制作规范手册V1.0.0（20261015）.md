## 1 前言 

RoboMaster 参赛队伍需自行研发和制作机器人。参赛机器人需满足本文档描述的所有规范，检录工作人 员会根据本文条例对机器人进行抽查。此外，参赛机器人需符合相关法律法规，不得存在安全隐患，若因 违规导致安全事故，组委会将依法追究违规方的法律责任。若本规范存在争议之处，以裁判长或检录长的 解释为准。 

为便于参赛队伍理解并遵守本手册条例，特此说明条例的约束力与可能后果： 

- 全文中凡在条目前标注“S#”（例如：S10）的条例，均为强制性条例，强制性条例侧重于安全、尺 寸/重量、电磁兼容性、场地规则等关键要求，必须严格遵守。违反强制性条例，组委会有权拒绝该机 器人参赛、要求限期整改或直接判定失去比赛资格，具体处理视违规性质而定。 

- 未标注“S#”的条例为建议性条例，建议性条例用于优化性能、提高稳定性或减少故障风险，但不作 为检录合格的硬性条件。未遵循建议性条例，虽不直接影响检录通过，但可能导致模块功能异常、比 赛中性能受限、发生额外的维修/定损费用或产生安全隐患；因此由此产生的一切损失与后果由参赛队 伍自行承担。 

除非在条例中另有说明，本手册中所有强制性条例均适用于RMUC 与RMUL 参赛机器人。若某项条例涉 及的机器人类别、场地道具或比赛规则与RMUL 无关，则RMUL 参赛机器人可被豁免该项具体要求。 

## 2 技术规范 

## 2.1 通用技术规范 

## 2.1.1 能源 

- S1 机器人使用的能源形式仅限于电源和气源。 

- S2 对于受底盘功率限制的机器人，其底盘水平方向移动的动力源仅限于电源。 

   - 禁止使用燃油驱动的发动机、爆炸物、危险化学材料。 

- 禁止在赛场区域内使用市电（雷达运算平台端除外）。 

- 禁止使用液压或其他有可能产生污染的动力方式。

## 2.1.1.2 气源 

- S9 气瓶中存储的压缩气体气压不得大于20Mpa，气瓶标称耐压值不得小于30Mpa，且在该气瓶出口 直接安装双表恒压阀，工作气压不得大于0.8Mpa。 

- S10 工作气体需满足不可燃烧、无毒、无污染的条件，如空气、氮气、二氧化碳。 

- S11 任何使用或存储气体的机构（气瓶、气缸、空气弹簧等）需要具有合格证书或铭牌钢印，检录时合 格证书、铭牌钢印需方便查看。 

- S12 若气瓶尚在寿命使用期内，需按说明书或铭牌规定的期限返厂维护，并且提供维护证明。 

- S13 气瓶需具备由原产地国家官方认可的认证机构颁发的认证证书。 

- S14 气瓶需安全稳固地安装于机器人机体上，瓶体至少有2 个距离大于1/5 瓶身长度的固定点或必须有 大于1/5 瓶身长度的固定面。气瓶及输气管需施以保护，以防止因机器人侧翻、碰撞、旋转、运动 部件故障等造成损坏。瓶口不得外露，防止被弹丸击打造成损坏。为确保安全，瓶口必须保持水平 或朝上。 

- S15 气瓶安装时需考虑机器人以任意角度翻滚，气瓶和输气管都不会接触到地面。 

- S16 输气管和配件需适用于系统可能的最大工作压力。 

- 建议低压气路安装安全泄压阀。 

- 建议距离气瓶50mm 内避免任何易燃材料。

## 2.2.1 充分再设计 

充分再设计是指对机器人核心机构的改进，相关系统的牵连较为广泛。 

1. 底盘 

   - 轮组方案改变。例如：麦克纳姆轮、舵轮、全向轮、阿克曼转向轮、履带等方案的改变； 

   - 轮组传动方案改变。例如：动力在簧下，动力在簧上等方案的改变； 

   - 悬架方案改变。例如：双叉臂悬架、扭力梁悬架、双纵臂悬架、升降悬架等方案的改变； 

   - 底盘动力改变。例如：直流、交流，有刷、无刷，减速、直驱等动力改变； 

   - 底盘形式改变。例如：框架式、板层式、承载式等底盘形式的改变。 

## 2. 云台 

- 云台传动堆叠改变。例如：Yaw、Pitch、Roll 轴包含关系、数量发生变化； 

- 供弹原理变更。例如：机器人供弹链路由简单直连供给变更为通过Yaw 轴关节供给至发射机构； 

- 弹仓位置变化。例如：弹仓和底盘固连、Yaw 轴固连、Pitch 轴固连等方式的改变； 

- 云台电机传动方式变化。例如：直驱、带轮、连杆、齿轮等方式的改变（不包括带轮、齿轮、链 轮之间的互换）。 

## 3. 执行机构 

- 除末端执行器的其他机构，拓扑结构的变化，例如：转动副、滑动副等的组合顺序、数量、类型 改变； 

- 执行机构的动力效率提升，例如：功能不变的情况下动力数量减少、有效功能增加的情况下动力 数量不变、有效功能增加的情况下动力数量增加。 

## 4. 飞镖系统 

- 飞镖镖体：总体气动构型或控制力生成方式改变。例如：由常规主翼—尾翼布局改为飞翼布局； 或对前、后部气动控制面的功能分配进行总体重构，并相应重新设计气动布局、执行机构和控制 配合。 

- 飞镖发射架：发射动力作用原理或核心传动拓扑改变；供镖、装填核心机构的运动链拓扑改变。 例如：由弹性储能弹射改为摩擦轮加速；重新设计驱动运动链，使动力输入、传递及作用于镖体 的方式发生原理性变化。 

## 5. 空中系统 

- 机库：出入库、转运或对接核心机构的原理或运动链拓扑改变。例如：由各机位独立停放、起降， 改为共用起降平台配合主动转运机构；由固定被动导向对接，改为主动多轴找正对接，并相应重 构感知、执行和控制配合。 

- 空中机器人：升力单元总体布置或姿态控制机构原理改变；机体主要承载体系改变。例如：由平 面分布旋翼改为共轴布置，或由固定轴旋翼改为主动倾转旋翼；实际改变动力单元、机载设备和 起落结构之间的载荷传递关系。 

## 2.2.2 非充分再设计 

非充分再设计是指与相关系统牵连较少的改进。 

- 关键参数变化幅度大于10%（如：悬架硬点位置，轮距、轴距，飞镖发射架有效加速行程，飞镖镖体， 空中机器人局部气动几何参数等）； 

- 有效动力轮组数量变化； 

- 底盘、云台、飞镖发射架、机库动力电机减速比或执行机构局部传动路径、传动方式变更； 

- 裁判系统机载端模块放置方位变化至少3 个模块，且均导致机器人系统出现拓扑结构变化； 

- 增加与机器人原功能相关联的新功能模块。例如：独立救援装置、图传小转台、能量单元转向、视觉 模块的增加；飞镖发射架装填、发射相关功能模块；空中系统、飞镖镖体感知、反馈，执行模块。 

- 摩擦轮纵置和横置变化； 

- 动力源的变更。例如：气动、电动； 

- 末端执行器的类型、方案变更。例如：旋转夹取，变为平移夹取； 

- 核心电子器件布局（主控、电源、运算平台、感知模块）。例如：位置从云台切换到底盘； 

- 云台旋转范围从有限变为无限； 

- 飞镖局部气动构件尺寸、数量或安装角度的调整，例如尾翼面积变化、尾翼安装角度变化、翼型弯度 调整等； 

- 飞镖材料更换，并在质量分布或表面特性方面进行调整； 

- 飞镖发射架供弹机构布局或结构形态的调整，如供弹轨道形状改变、推弹机构形状优化等； 

- 发射架部件间传动比或传动路径的修订。 

## 2.2.3 无效再设计 

无效再设计是指对核心功能影响较小的改动。 

无效再设计包括但不限于以下改动： 

- 非主要承重结构、遮罩防护结构改动。例如：镂空发生变化、形状发生变化； 

- 标准件型号数量的变更； 

- 气缸和电推杆互换； 

- 常规配重调平、仅换舵机或电池型号、只修改与发射架配合的挂载接口； 

- 同特性材质的变换。例如：玻纤板和碳纤板互换； 

- 原理无变化的变更。例如：上供弹硬管改软管等硬度的改变； 

- 机库仅换外箱、舱盖形状，复制相同停机位； 

- 空中机器人只更换桨叶、电机、电池或飞控型号，只修改PID 或现成固件配置，以及只增加非主要承 载的桨保； 

- 飞镖发射架仅更换电机、弹簧、皮筋规格，仅改变外壳或飞镖挂载方式。

- 通用算力不高于25GHz，通用算力计算方式：对所有处理器核心的标称基准主频逐核求和（即 Σ(主频*核数)≤25GHz）。

## 2.4 机器人技术规范 

- 最大收纳尺寸：机器人需存在一种状态满足最大收纳尺寸限制，包含裁判系统及其支架。 

      - 最大伸展尺寸：机器人任意时刻的最大尺寸限制，以机器人机械结构可能展开到极限姿态为 准，包含裁判系统及其支架。组合系统与系统单元存在物理连接时，所连接的系统单元均计 入组合系统的最大伸展尺寸。在检录时，参赛队伍需主动展示所有的机械结构变形情况，在 变形前、中、后机器人任意形态均不得超过最大伸展尺寸要求。 

      - 本节中，机器人的长、宽、高分别对应机体坐标系的X 轴、Y 轴、Z 轴方向上的长度。其中， 空中机器人、雷达的X 轴、Y 轴方向任选，Z 轴垂直于其放置平面，飞镖系统不适用坐标系 相关规范。 

- S66 除雷达系统、自定义终端、模块化42mm 发射机构外，机器人在尺寸发生变化时不得被拆分为独立 单体；同时连接结构需满足下列要求： 

   - 允许使用机械铰接或球接（例如：合页、转轴、球头轴承、直线导轨）、其他通过实体本体结构互 锁的可动连接。 

   - 禁止使用柔性牵引连接（例如：线缆、绳索、链条、皮带）、依赖吸附/摩擦维持的连接（例如： 吸盘、磁吸、仅靠摩擦力的连接）。 

- 螺丝、扎带等零件的松紧调节但不拆除不视为拆分为独立单体。

- S120 机器人进行装甲模块安装时，装甲模块和装甲支撑架需稳固连接。装甲模块的装甲支撑架底部连接 面需与XY 平面平行，使得装甲模块受力面所在平面的法向量所在直线与Z 轴负方向所在直线的锐 角夹角为75°。装甲模块不含侧灯的两条边与XY 平面夹角小于5°。定义安装好的装甲模块受击打面 的法向量（与Z 轴负方向夹角为锐角）在XY 平面上的投影为该装甲模块的方向向量。4 块装甲模 块的方向向量需分别与机器人机体坐标系的正X 轴、负X 轴、正Y 轴、负Y 轴一一对应，方向向 量和对应坐标轴之间的角度误差不能超过5°。 

- S121 机器人本身的运动学方程也需建立在上述机体坐标系下。装甲模块的安装方式需与机器人本身的结 构特性或者运动学特性共享同一个参考坐标系。X 轴上安装的装甲模块几何中心点连线与Y 轴上安 装的装甲模块几何中心点连线要互相垂直。安装于Y 轴的单个装甲模块在发生偏移后，其几何中心 相对于机器人的几何中心的偏移量在X 轴上的分量不得超过50mm，安装于X 轴上的装甲模块同 理。

## 3.12 超级电容管理模块安装规范 

超级电容管理模块用于检测超级电容模组的容值，以及检测比赛过程中的超级电容模组能量。超级电容管 理模块的尺寸预计为60*30*7.5mm（L*W*H），使用热缩管作为模块的外部保护。 

硬件接口包括1 个XT30 公头、2 个XT30 母头和1 个超级电容管理模块通信接口。 

- XT30 母头型号为XT30PW-F。 

- XT30 公头型号为XT30PW-M。 

## 3.12.1 安装步骤 

功率控制板是调节电源管理模块Chassis 接口的输出功率和超级电容模组的输入功率、输出功 率以满足规则中功率限制的模块。此模块为参赛队伍自制。 

1. 将超级电容管理模块安装在超级电容模组的输出接口与功率控制板的输入接口之间。 

2. 使用带XT30 接口的线材连接超级电容模组与超级电容管理模块。 

3. 使用带XT30 接口的线材连接功率控制板与超级电容管理模块。 

4. 使用4-pin 连接线连接超级电容管理模块的通信接口与电源管理模块的CAN1 接口。
