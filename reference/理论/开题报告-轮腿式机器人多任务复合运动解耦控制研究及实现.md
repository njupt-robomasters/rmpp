# 《轮腿式机器人多任务复合运动解耦控制研究及实现》开题报告

> 论文形式：应用技术研究论文　　论文类型：应用研究

---

## 一、选题依据（综述报告）

### 1.1 研究背景

轮腿式机器人在腿部末端装有主动驱动轮，平坦路面上靠轮式滚动实现高速、高能效的移动，遇到台阶、坡道、沟坎等非结构化地形时，靠腿部伸缩和摆动实现越障、调高和跳跃。它兼有轮式机器人“快”和足式机器人“通过性好”的优点，在巡检安防、物流配送、应急救援、特种作业和教育竞赛（如 RoboMaster 平衡步兵）等领域应用前景很广。

双轮轮腿机器人本质上是一个**欠驱动、开环不稳定、强耦合的非线性系统**。它的动力学可以抽象为“驱动轮 + 可变长虚拟腿 + 机体”组成的多级倒立摆，必须依靠持续的主动反馈才能保持平衡。实际作业中，机器人往往要**同时**完成好几个运动任务：

- **平衡任务**：维持机体俯仰角稳定；
- **移动任务**：跟踪期望的前进速度和位移；
- **转向任务**：跟踪偏航角或偏航角速度；
- **调高任务**：根据地形和作业需求改变机体高度，也就是腿长；
- **横滚稳定任务**：在侧坡、单侧越障或高速转弯时维持机体水平；
- **跳跃与越障任务**：完成蓄力、起跳、收腿、着陆等动作序列。

这些任务在动力学上是深度耦合的。腿长变化会改变质心高度和转动惯量，让平衡控制的最优增益大幅变化。纵向加减速会通过倒立摆效应直接引起俯仰扰动。高速转弯产生的离心力会诱发横滚倾覆力矩。左右腿长不对称会破坏两侧动力学的对称性，引入交叉耦合。腾空和着地切换则让系统结构（接触约束）发生突变。如果对这些任务分别独立设计控制器、简单叠加，多任务同时执行时常出现俯仰振荡、调高过程跌倒、转弯侧翻等问题。所以，研究**多任务复合运动下的解耦控制方法**，并在实际平台上实现，有很强的理论意义和工程价值。

### 1.2 国内外研究现状

#### 1.2.1 两轮倒立摆与轮腿机器人平台

两轮自平衡机器人的研究始于二十世纪末。Grasser 等研制的 JOE 机器人[1]是早期的代表，它建立了两轮倒立摆的线性化模型，用状态反馈实现了平衡与移动控制，此后的 Segway 等产品推动了这类技术的商业化。Kim 等[2]系统推导了两轮倒立摆移动机器人的动力学模型，为后续研究提供了建模基础。

在这个基础上，研究者给两轮平衡机器人加上腿部自由度，形成双轮轮腿机器人。瑞士苏黎世联邦理工学院（ETH）的 Ascento[3]用并联连杆腿和 LQR 控制实现了双轮跳跃。后续工作[4]把 LQR 和全身控制（WBC）结合，处理含闭链运动学回路的轮腿机器人的多任务控制。ETH 的 ANYmal 轮足四足机器人[5,6]用全身模型预测控制（MPC）和分层优化，实现了轮式滚动与步态行走的协同。Zambella 等[7]研究了不稳定轮式人形机器人的动态全身控制。国内方面，腾讯 Robotics X 实验室的 Ollie 轮腿机器人[8,9]在平衡控制、欠驱动跳跃规划和空翻等高动态动作上取得了有代表性的成果。中山大学团队提出的 DIABLO 全直驱 6 自由度轮腿机器人[10]把 LQR 与 WBC 结合，并开源了相关资料。

#### 1.2.2 轮腿机器人建模与平衡控制方法

**(1) 建模方法。** 主流做法是把轮腿机器人抽象为“轮—虚拟腿—机体”的轮腿倒立摆（WLIP）模型，用牛顿-欧拉法或拉格朗日法建立非线性动力学方程，再在平衡点处线性化，得到状态空间模型[11,12]。按状态维度可分为两类：**6 维双腿独立建模**（每条腿单独运行 LQR，偏航另加差速 PD），结构简单但表达不了左右腿的耦合；**10 维整体建模**（状态包含位移、偏航、俯仰和左右腿摆角及其导数），可以在单一的 4×10 反馈矩阵中表达左右腿的交叉耦合，更适合非对称工况。

**(2) 平衡控制。** 线性二次型调节器（LQR）实现简单、能自然处理多变量耦合，是轮腿平衡控制的主流方法。LQR 依赖平衡点附近的线性模型，而腿长变化会让模型参数显著改变，所以通常要配合**增益调度**[13]：离线在多个腿长采样点上求解 LQR，再用多项式拟合 K(L)，运行时在线插值。陈阳等[14]把 LQR、增益调度和虚拟模型控制（VMC）结合，实现了轮腿平衡机器人的变高度控制。

**(3) 腿部力控。** 虚拟模型控制（VMC）[15]基于虚功原理 τ = JᵀF，把任务空间里的虚拟力和力矩映射为关节力矩，让控制器设计和机构几何解耦。它是轮腿机器人腿长控制、横滚控制和腿部摆角执行层的常用方法。

**(4) 先进控制方法。** 为了处理约束、扰动和多任务冲突，研究者引入了模型预测控制（MPC）[5]、全身控制与任务优先级框架[4,16,17]、扩展状态观测器（ESO）和自抗扰控制（ADRC）[18]等方法。谢景硕等[19]把 MPC 和 ESO 扰动观测器用在串联式四轮腿机器人的姿态控制上。任晓磊等[20]采用单刚体动力学模型加二次规划力矩分配，实现了轮腿复合机动平台的运动控制。刘辉等[21]针对轮腿式平台的多任务复合运动，提出了基于前馈补偿的解耦控制方法，并分析了质心速度跟踪误差。

#### 1.2.3 多任务解耦与任务优先级控制

在冗余机器人领域，Siciliano 和 Slotine[16]提出的零空间投影任务优先级框架，奠定了多任务分层控制的理论基础。Kanoun 等[17]把它推广到不等式任务约束。足式和轮腿机器人的全身控制（WBC）[4,6]通过分层二次规划（HQP），让高优先级任务（平衡、接触约束）严格满足，低优先级任务在零空间内尽量满足。这类方法理论完备，但计算量大，对嵌入式平台的实时性要求高。对于资源受限的微控制器平台，工程上更常用的是**“分层控制架构 + 增益调度 + 前馈补偿”**的轻量级解耦方案：用 LQR 处理矢状面平衡、移动和偏航的强耦合子系统，用 VMC 加 PID 处理腿长和横滚这类相对独立的通道，再用前馈补偿抵消可建模的跨通道耦合项。

#### 1.2.4 状态估计与接触检测

LQR 需要全状态反馈，但水平位移和速度不能直接测量。常用做法是用 Kalman 滤波[22]把 IMU 加速度和轮式里程计融合起来。姿态解算方面，VQF 算法[23]在零偏估计和抗运动加速度干扰上表现优秀。轮子打滑、离地、卡滞等异常接触状态会严重破坏状态估计和控制性能，需要基于动力学的地面支持力观测和打滑检测机制来识别，并据此切换控制策略。另外，Doyle[24]指出 LQG 结构的鲁棒裕度没有理论保证，这说明实机系统必须配套失稳检测和安全保护机制。

#### 1.2.5 国内工程实践现状

在 RoboMaster 机甲大师赛的带动下，国内高校围绕轮腿平衡步兵积累了大量工程实践。哈尔滨工程大学团队较早完整推导并公开了 WLIP 模型；上海交通大学团队提出的串联腿构型（髋膝独立控制 + 内部五连杆传动）具备倒地自起和单腿跨台阶的能力，成为构型上的分水岭；北京科技大学、深圳大学等团队开源了 LQR + VMC + Kalman 完整电控框架和仿真工程。这些实践验证了“LQR + 增益调度 + VMC”技术路线的可行性，但大多以竞赛实用为导向，缺少对多任务耦合机理的系统分析和对解耦效果的定量评价。

### 1.3 发展趋势

1. **从单任务稳定走向多任务协同**：从“能站稳”发展到“边走边调高、边转弯边越障”的复合运动能力，多任务之间的耦合抑制和优先级协调成为核心问题；
2. **从对称工况走向非对称工况**：单腿越障、侧坡站立、左右腿独立伸缩等非对称工况要求控制器显式处理左右腿交叉耦合，10 维整体建模和二维增益调度 K(L_l, L_r) 逐渐成为研究重点；
3. **从纯反馈走向“反馈 + 前馈 + 观测”的复合控制**：利用模型信息前馈补偿重力、离心力、加速度耦合等可预知项，结合扰动观测器抑制未建模扰动；
4. **从仿真验证走向嵌入式实机部署**：在计算资源受限的 MCU 上实现高频（≥500 Hz）、低抖动的实时控制，要求“离线重计算、在线轻量化”的工具链；
5. **学习方法与模型方法融合**：强化学习等数据驱动方法开始用于轮腿机器人运动控制，与基于模型的方法互为补充。

### 1.4 研究意义、先进性与实用性

**理论意义。** 本课题以串联腿轮腿机器人为对象，系统分析平衡、移动、转向、调高、横滚和跳跃等多任务之间的动力学耦合机理，提出适合嵌入式实时实现的分层解耦控制架构，丰富欠驱动轮腿系统多任务协调控制的理论方法。

**工程价值。** 研究成果可以直接用于实验室或竞赛轮腿平台，提升机器人在复杂地形、复合运动下的稳定性和机动性；形成的“建模—离线计算—仿真验证—嵌入式部署—实机调试”完整工具链有较好的可复用性，可为同类轮腿机器人的研发提供参考。

**先进性。**

- 面向**串联腿 + 内部五连杆传动**这一新构型，建立“电机空间—关节空间—任务空间”三层映射下的完整运动学、动力学模型；
- 采用 **10 维整体状态空间模型 + 二维增益调度 K(L_l, L_r)**，显式处理左右腿非对称工况下的交叉耦合；
- 构建 **“LQR 强耦合子系统 + VMC 弱耦合通道 + 前馈补偿与扰动观测”** 的双层解耦架构，兼顾解耦效果和嵌入式实时性。

**实用性。** 方案以成熟的 LQR、VMC、Kalman 滤波为基础，在线计算只包括多项式求值、矩阵与向量乘法和 2×2 雅可比映射，可以在 STM32 等主流微控制器上以 1 kHz 量级的频率运行，工程落地性强。

### 1.5 技术难度及工作量

**技术难点：**

1. 串联腿含内部五连杆闭链传动，“电机—关节—任务空间”多层映射的建模、标定和极性一致性验证难度较大；
2. 10 维非线性模型的符号推导与线性化计算量大，二维增益调度需要在 N×N 网格上反复求解 LQR，并保证拟合的数值稳定性；
3. 多任务耦合机理复杂，需要分析清楚各任务间的耦合通道，并分别设计反馈、前馈或观测补偿措施；
4. 打滑、离地、着陆冲击等接触状态切换会造成模型突变，要求控制器能平滑切换、安全降级；
5. 仿真到实机存在模型误差、传感器噪声、执行器延迟等差异，实机调试风险高、周期长。

**工作量：** 涵盖理论建模、离线工具链开发（Python/SymPy/MATLAB）、MuJoCo 仿真平台搭建、嵌入式软件开发（C + FreeRTOS，含驱动层、算法层、任务层）、实机分阶段调试和系统性对比实验，预计总工作量约 16～18 个月，满足研究生学位论文的工作量要求。

## 二、课题内容及具体方案

### 2.1 研究目标

以串联腿双轮轮腿机器人为对象，揭示平衡、移动、转向、调高、横滚和跳跃等多任务复合运动之间的动力学耦合机理，构建一套能在嵌入式平台上实时运行的分层解耦控制方法，并在仿真和实机上验证：在多任务同时执行时，该方法的俯仰稳定性、轨迹跟踪精度和抗扰能力明显优于传统的独立控制方案。

### 2.2 研究内容

**研究内容一：串联轮腿机器人运动学与动力学建模**

1. 建立“电机空间 → 关节空间 → 任务空间”三层运动学映射：推导内部五连杆传动的正解和逆解、串联腿正逆运动学（FK/IK），以及雅可比矩阵 J 和传动雅可比 J_trans，并用数值差分交叉验证解析结果；
2. 用拉格朗日法建立 10 维整体动力学模型，广义坐标为 q = [x, ψ, θ, θ_L, θ_R]ᵀ，状态向量为 x ∈ ℝ¹⁰，控制向量为 u = [τ_L, τ_R, T_wL, T_wR]ᵀ。模型考虑质心偏移和腿部质量分布随腿长的变化；
3. 在平衡点处线性化得到 (A, B)，检验可控性和可观测性，并对比分析 6 维独立模型与 10 维整体模型的差异。

**研究内容二：多任务耦合机理分析与分层解耦控制架构设计**

1. 把复合运动划分为若干子任务：矢状面平衡、速度跟踪、偏航跟踪、腿长（高度）跟踪、横滚稳定和跳跃；
2. 通过模型分析和仿真激励实验，定量刻画主要耦合通道：
   - 腿长变化 → 动力学参数和平衡点偏移 → 俯仰扰动；
   - 纵向加减速 → 倒立摆效应 → 俯仰扰动；
   - 偏航转弯 → 离心力 → 横滚倾覆力矩；
   - 左右腿长不对称 → 交叉耦合与横滚；
   - 接触状态切换 → 模型结构突变；
3. 设计双层解耦架构：
   - **上层（强耦合子系统）**：10 维 LQR 统一处理平衡、速度和偏航，由 K 矩阵中的交叉项自然协调左右腿耦合；
   - **下层（弱耦合通道）**：在任务空间用 VMC 实现腿长“位置—速度”级联控制和横滚 PD 控制，经 J 转置和传动逆解输出关节力矩；
   - **跨层补偿**：用前馈和观测补偿处理上下层之间的耦合项（见研究内容四）。

**研究内容三：基于二维增益调度的变构型 LQR 设计**

1. 用 ZOH 离散化，求解离散 Riccati 方程（DARE），用 Bryson 法则给出 Q/R 初值，再迭代优化；
2. 在 (L_l, L_r) 二维网格上离线求解 K 矩阵和平衡偏移量，用 Chebyshev 正交基做二维多项式拟合，同时比较一维 K(L) 与二维 K(L_l, L_r) 两种方案；
3. 把平衡偏移量 x_eq(L_l, L_r) 纳入控制律 u = −K(x − x_target + x_eq)，消除变腿长引起的稳态偏差；
4. 分析准静态假设下增益调度的稳定性条件，并给出腿长变化速率的约束。

**研究内容四：基于前馈补偿与扰动观测的耦合抑制方法**

1. **重力与高度前馈**：根据腿长和姿态计算轴向重力前馈 F_g，以及俯仰方向随高度变化的重力矩补偿；
2. **加速度前馈**：由期望速度轨迹计算期望加速度，并据此计算对应的平衡倾角前馈，降低加减速时的俯仰超调；
3. **离心力前馈**：根据偏航角速度和前进速度估计离心力，前馈注入横滚通道的左右腿轴向力差；同时按质心高度给出转向角速度的安全上限，满足 ω_max ∝ √(g·d/h)；
4. **模型残差补偿与扰动观测**：用离散模型一步预测残差 e = x_{k+1} − (A_d x_k + B_d u_k) 估计轮端集总扰动，或设计 ESO 观测器，补偿到轮毂力矩通道；
5. 对比“无补偿 / 仅反馈 / 反馈 + 前馈 / 反馈 + 前馈 + 观测”四种方案的解耦效果。

**研究内容五：状态估计与接触状态检测**

1. 用 VQF 解算姿态，用二维 Kalman 滤波融合 IMU 世界系加速度和轮式里程计，估计位移和速度；
2. 基于动力学的地面支持力观测，用于离地检测；结合轮速和加速度一致性做打滑检测，打滑时动态调整 Kalman 滤波的观测噪声；
3. 设计接触状态驱动的控制模式切换逻辑：腾空时把 LQR 降维为只保留腿部姿态反馈，着陆时缓冲；
4. 设计跳跃力控有限状态机（READY—CROUCH—LAUNCH—TUCK—LANDING—RECOVER），并设计失稳检测和倒地自救援的安全保护逻辑。

**研究内容六：仿真平台搭建与嵌入式实机实现**

1. 搭建 MuJoCo 仿真模型，注入传感器噪声、零偏、执行器延迟和力矩饱和等非理想因素；
2. 开发 Python/SymPy（或 MATLAB）离线工具链，实现“建模 → 线性化 → LQR → 拟合 → 导出 C 头文件”的一键生成；
3. 在 STM32 + FreeRTOS 平台上实现三层软件架构（驱动层、算法层、任务层），控制周期不低于 500 Hz，并验证 float32 数值精度和实时性；
4. 按“单关节开环 → 板凳模型 → 释放腿部 → 移动转向 → 跳跃与地形”的顺序分阶段完成实机调试和验证。

### 2.5 实验方案

**对比方案：**

- **基线 1**：6 维双腿独立 LQR + 固定增益 + 独立 PID（不做解耦处理）；
- **基线 2**：10 维 LQR + 一维增益调度（不做前馈补偿）；
- **本文方法**：10 维 LQR + 二维增益调度 + 平衡偏移补偿 + 前馈与观测补偿。

**实验工况与评价指标：**

| 实验 | 工况 | 主要评价指标 |
|---|---|---|
| E1 静态平衡与抗扰 | 不同腿长下施加冲击扰动 | 俯仰角峰值、恢复时间、位移偏差 |
| E2 移动—平衡耦合 | 速度阶跃、加减速 | 速度跟踪 RMSE、俯仰角峰值与 RMS |
| E3 调高—平衡耦合 | 行进中连续变腿长 | 腿长跟踪误差、俯仰波动、速度波动 |
| E4 转向—横滚耦合 | 不同速度下转弯 | 横滚角峰值、偏航跟踪误差 |
| E5 非对称工况 | 侧坡站立、单侧过障 | 横滚角、左右腿长误差、俯仰波动 |
| E6 复合运动 | 移动 + 调高 + 转向同时执行 | 综合跟踪误差、跌倒次数 |
| E7 跳跃与着陆 | 原地跳、越障跳 | 跳跃高度、着陆后恢复时间、成功率 |
| E8 实时性 | 嵌入式运行 | 控制周期抖动、最坏执行时间、CPU 占用 |

每组实验重复 5 次以上，统计均值和标准差。仿真与实机结果对照分析，评估模型误差的影响。

### 2.6 可行性分析

1. **理论可行性**：LQR、增益调度、VMC、Kalman 滤波等理论成熟，在两轮倒立摆和轮腿机器人上已有大量成功应用[3,4,8,14]，本课题的解耦架构建立在成熟理论之上，没有原理性障碍；
2. **技术可行性**：社区已有串联腿与五连杆轮腿的开源建模、仿真和电控工程，可作参考；“离线重计算、在线轻量化”的方案把在线计算量控制在少量多项式求值和小规模矩阵运算，满足 MCU 实时性要求；
3. **条件可行性**：依托实验室或战队现有的轮腿机器人平台，以及关节电机、轮毂电机、IMU、主控板等硬件，同时具备 MuJoCo、Python、MATLAB、Keil 等软件环境；
4. **风险与对策**：实机极性错误和失稳风险，用分阶段逐层调试、软硬件急停和防护垫来降低；仿真到实机的差异，通过注入非理想因素、标定质心和传动参数来缩小；如果二维增益调度在实机上的收益有限，就退回一维方案，把研究重点放在前馈与观测补偿上，保证主线工作能按期完成。
