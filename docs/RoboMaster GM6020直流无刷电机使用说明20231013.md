# RoboMaster GM6020 直流无刷电机使用说明

> 根据《RoboMaster GM6020 直流无刷电机使用说明 20231013》（v1.4，2023.10）整理。为便于检索和编写控制代码，省略免责声明、图片和性能曲线，保留接口、配置、通信协议及规格信息。若本文与原 PDF 有歧义，以原 PDF 为准。

## 产品概述

GM6020 是集成驱动器和角度传感器的直流无刷电机，使用 FOC 控制。

- 支持 CAN 和 PWM，并可识别两种信号自动切换模式
- CAN 模式支持转矩电压或转矩电流闭环；速度和位置环由外部控制器根据反馈实现
- PWM 模式支持速度和位置闭环
- 可通过 CAN 获取机械角度、转速、转矩电流和温度
- 通过拨码开关设置 ID 和 120 Ω CAN 终端电阻
- 额定供电电压：DC 24 V

固件版本不低于 1.0.11.2 且 RoboMaster Assistant 不低于 2.7 时，可在参数设置中打开电流环，使用转矩电流控制。

## 使用注意事项

- 遵守工作环境温度及绕组最高允许温度
- 防止杂物进入转子内部，远离强磁场和铁制品等导磁材料
- 上电前确认接线和安装正确、稳固，线材无损伤
- 大转矩输出时电机会发热
- 不要私自拆卸电机

## 接口与线序

1. **CAN 端口**：接收 CAN 控制指令并反馈状态，比特率 1 Mbps
2. **电源接口**：通过 XT30 连接额定 24 V 电源
3. **PWM 端口**：接收 PWM 速度或位置指令；也兼作串口调参端口
4. **指示灯**：显示正常、警告和异常状态
5. **拨码开关**：设置电机 ID 和 CAN 终端电阻

| 接口 | 从上到下的线序 |
| --- | --- |
| CAN | A 红色 `CAN_H`、B 黑色 `CAN_L` |
| PWM/串口 | A 白色 `PWM/RX`、B 灰色 `TX`、C 黑色 `GND` |

从输出轴端观察，逆时针（CCW）为正方向，顺时针（CW）为反方向。

## 拨码开关

### ID 设置

拨码开关第 1～3 位依次为 `Bit0`、`Bit1`、`Bit2`，拨至 `ON` 表示 1。ID 在重新上电后按当前拨码值生效。

| `Bit[2:0]` | 电机 ID | 反馈标识符 | 控制标识符（电压/电流） |
| --- | ---: | --- | --- |
| `000` | 无效 | — | — |
| `001` | 1 | `0x205` | `0x1FF` / `0x1FE` |
| `010` | 2 | `0x206` | `0x1FF` / `0x1FE` |
| `011` | 3 | `0x207` | `0x1FF` / `0x1FE` |
| `100` | 4 | `0x208` | `0x1FF` / `0x1FE` |
| `101` | 5 | `0x209` | `0x2FF` / `0x2FE` |
| `110` | 6 | `0x20A` | `0x2FF` / `0x2FE` |
| `111` | 7 | `0x20B` | `0x2FF` / `0x2FE` |

### CAN 终端电阻

拨码开关第 4 位拨至 `ON` 时接入 120 Ω 终端电阻。

## CAN 通信协议

### 基本参数

- CAN 比特率：1 Mbps
- 帧类型：标准帧
- 帧格式：数据帧
- DLC：8 字节
- 所有 16 位值均为高字节在前、低字节在后

### 电压控制报文

给定值为 16 位有符号数，范围 -25000～25000。一帧最多控制 4 个电机。

| ID 范围 | 标识符 | 数据布局 |
| --- | --- | --- |
| 1～4 | `0x1FF` | `DATA[0:1]`～`DATA[6:7]` 依次对应 ID 1～4 |
| 5～7 | `0x2FF` | `DATA[0:1]`、`DATA[2:3]`、`DATA[4:5]` 对应 ID 5～7；`DATA[6:7]` 未使用 |

### 电流控制报文

给定值为 16 位有符号数，范围 -16384～16384，对应最大转矩电流 -3～3 A：

`current_A = command * 3 / 16384`

| ID 范围 | 标识符 | 数据布局 |
| --- | --- | --- |
| 1～4 | `0x1FE` | `DATA[0:1]`～`DATA[6:7]` 依次对应 ID 1～4 |
| 5～7 | `0x2FE` | `DATA[0:1]`、`DATA[2:3]`、`DATA[4:5]` 对应 ID 5～7；`DATA[6:7]` 未使用 |

向未开启电流环的电机发送电流控制报文不会得到预期的电流控制。电流控制模式下收到电压指令时，电机以橙灯常亮警告。

### 反馈报文

- 标识符：`0x204 + 电机 ID`，即 ID 1～7 对应 `0x205`～`0x20B`
- 发送频率：1 kHz

| 字节 | 内容 | 类型或单位 |
| --- | --- | --- |
| `DATA[0:1]` | 机械角度 | 0～8191 对应一圈 |
| `DATA[2:3]` | 转速 | rpm |
| `DATA[4:5]` | 实际转矩电流 | 16 位原始值 |
| `DATA[6]` | 电机温度 | ℃ |
| `DATA[7]` | 未使用 | `Null` |

## PWM 控制

- 输入频率：50 Hz
- 脉宽行程：1000～2000 μs
- 可在 RoboMaster Assistant 中选择速度或位置模式，默认为位置模式

### 速度模式

控制电机双向连续转动。脉宽前半段对应反向转速，中点对应零速，后半段对应正向转速；原手册中的具体映射曲线未转换。

### 位置模式

将电机作为模拟舵机使用。中点位置和转角范围可在 RoboMaster Assistant 中设置；原手册中的具体映射曲线未转换。

### PWM 行程校准

1. 将控制设备的 PWM 输出连接到电机 PWM 端口
2. 将脉宽设为最大行程 1900～2100 μs，再给电机上电；绿灯常亮表示正在校准
3. 在 3 秒内将脉宽设为最低行程 900～1100 μs
4. 成功后保存行程并进入正常模式，绿灯慢闪；失败时参数不变，橙灯快闪

## 指示灯

异常状态下驱动器关闭输出。多个警告或异常同时存在时，显示闪烁次数最少的状态；异常优先于警告。

| 类别 | 指示 | 含义 |
| --- | --- | --- |
| 正常 | 绿灯每秒闪 N 次 | CAN 正常，当前 ID 为 N |
| 正常 | 绿灯慢闪 | PWM 通信正常 |
| 校准 | 绿灯常亮 | PWM 行程校准中 |
| 警告 | 橙灯每秒闪 1 次 | 电机温度 >100 ℃ |
| 警告 | 橙灯每秒闪 2 次 | CAN 总线上存在重复 ID |
| 警告 | 橙灯每秒闪 3 次 | PWM 信号无法识别 |
| 警告 | 橙灯每秒闪 4 次 | 温度传感器异常 |
| 警告 | 橙灯快闪 | PWM 行程校准失败 |
| 警告 | 橙灯常亮 | 电流控制模式下收到电压指令 |
| 异常 | 红灯每秒闪 1 次 | 供电电压过高 |
| 异常 | 红灯每秒闪 4 次 | 电机温度 >125 ℃ |

## RoboMaster Assistant

使用 PWM 信号线连接 USB 转串口工具：黑色接 `GND`，灰色为电机 `TX`，白色为电机 `PWM/RX`。完成参数设置或固件升级前不要断电或断开连接。

## 机械参数

- 转子端：3 个 M3 螺纹孔，深 4 mm
- 定子端：3 个 M4 螺纹孔，深 6 mm
- 转子端和定子端均有外径 22 mm、内径 18 mm、高 1.5 mm 的定位凸台
- 空心轴内径：18 mm
- 电机外径：66.7 mm
- 总高度：45 mm
