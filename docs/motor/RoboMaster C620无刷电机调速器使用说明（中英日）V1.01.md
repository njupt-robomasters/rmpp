# RoboMaster C620 无刷电机调速器使用说明

> 根据《RoboMaster C620 无刷电机调速器使用说明（中英日）V1.01》（2017.09，V1.0）中文版整理。为便于检索和编写控制代码，省略重复的英文、日文内容、免责声明、图片和性能曲线，保留接口、配置、通信协议及规格信息。若本文与原 PDF 有歧义，以原 PDF 为准。

## 产品概述

C620 使用 FOC 控制，与 M3508 直流无刷减速电机配套使用。

- 支持 CAN 总线控制和 50～500 Hz PWM 控制
- 最大持续电流：20 A
- 支持为同一 CAN 总线上的电调快速设置 ID
- CAN 模式下可反馈电机温度、转子位置和转速
- 额定供电电压：DC 24 V

## 使用注意事项

- 不允许同时连接 CAN 和 PWM 端口，否则可能造成电机失控
- 切换控制方式前必须切断电调电源
- 大功率输出时电调会发热，注意防止烫伤
- 严格遵守额定电压、电流和温度范围

## 接口与接线

1. **7-Pin 电机数据端口**：连接 M3508 进行数据交互
2. **三相动力线接头**：同色线对应连接 M3508，不可接错
3. **CAN 终端电阻开关**：`ON` 接入 120 Ω，`OFF` 断开 120 Ω
4. **SET 按键**：设置 ID 和执行电机校准
5. **电源线**：额定 24 V，插头兼容 XT30
6. **指示灯**：显示工作、警告和异常状态
7. **CAN 端口**：1 Mbps CAN 控制
8. **PWM 端口**：接收 PWM；也用于连接 USB 转串口工具调参和升级

### 线序

| 接口 | 从上到下的线序 |
| --- | --- |
| CAN | A 黑色 `CAN_L`、B 红色 `CAN_H` |
| PWM/串口 | A 黑色 `GND`、B 灰色 `TX`、C 白色 `PWM/RX` |

## SET 按键操作

### 单独设置 ID

ID 范围为 1～8。

1. 正常工作时短按一次 SET，进入单独设置模式，指示灯熄灭
2. 再短按 SET，按键次数即为 ID；最多按 8 次，每次有效按键橙灯闪一次
3. 停止操作 3 秒后自动保存，重新上电后生效

同一 CAN 总线上不得有重复 ID，否则冲突电调会告警并关闭输出。

### 快速设置 ID

1. 短按任意一个电调的 SET 进入单独设置模式，再长按 SET
2. 总线上最多 8 个电调进入快速设置模式，全部橙灯常亮
3. 按期望的 ID 顺序，依次手动将相应 M3508 转子向任意方向旋转至少半圈
4. 电调按转动顺序自动分配 ID 1、2、3……；重新上电后生效

未转动的电机保持原 ID。

### 电机校准

更换电机或电调后可执行校准，以获得更好的适配参数。

1. 正确连接电机和电调并上电
2. 长按 SET，直到绿灯快闪后松开
3. 电机自动校准，完成后自动退出

校准期间电机会转动，应空载操作且不要触碰。

## CAN 通信协议

### 基本参数

- CAN 比特率：1 Mbps
- 帧类型：标准帧
- 帧格式：数据帧
- DLC：8 字节
- 所有 16 位值均为高字节在前、低字节在后

### 控制报文

控制量为 16 位有符号转矩电流给定值：

- 数值范围：-16384～16384
- 对应转矩电流：-20～20 A
- 换算：`current_A = command * 20 / 16384`

#### ID 1～4

- 标识符：`0x200`

| 字节 | 内容 |
| --- | --- |
| `DATA[0:1]` | ID 1 控制电流，高 8 位在前 |
| `DATA[2:3]` | ID 2 控制电流，高 8 位在前 |
| `DATA[4:5]` | ID 3 控制电流，高 8 位在前 |
| `DATA[6:7]` | ID 4 控制电流，高 8 位在前 |

#### ID 5～8

- 标识符：`0x1FF`

| 字节 | 内容 |
| --- | --- |
| `DATA[0:1]` | ID 5 控制电流，高 8 位在前 |
| `DATA[2:3]` | ID 6 控制电流，高 8 位在前 |
| `DATA[4:5]` | ID 7 控制电流，高 8 位在前 |
| `DATA[6:7]` | ID 8 控制电流，高 8 位在前 |

### 反馈报文

- 标识符：`0x200 + 电调 ID`，例如 ID 1 使用 `0x201`
- 默认发送频率：1 kHz，可在 RoboMaster Assistant 中修改

| 字节 | 内容 | 类型或单位 |
| --- | --- | --- |
| `DATA[0:1]` | 转子机械角度 | 0～8191 对应 0～360° |
| `DATA[2:3]` | 转子转速 | rpm |
| `DATA[4:5]` | 实际转矩电流 | 16 位原始值 |
| `DATA[6]` | 电机温度 | ℃ |
| `DATA[7]` | 未使用 | `Null` |

## PWM 控制

- 频率：50～500 Hz
- 可校准脉宽范围：1000～2000 μs
- 可在 RoboMaster Assistant 中设置单向或双向转动、旋转方向和其他 PWM 参数
- 默认正方向：从电机输出轴方向观察为逆时针

单向模式下，脉宽从最小到最大对应速度从 0 增加到正向最大值。双向模式下，前半行程对应反向最大速度到 0，后半行程对应 0 到正向最大速度。原手册中的具体映射曲线未转换。

### PWM 行程校准

1. 将控制设备 PWM 输出连接到电调 PWM 端口
2. 将脉宽设为最大行程，连接电机并给电调上电；绿灯常亮表示进入校准
3. 在 3 秒内将脉宽设为最小行程
4. 成功后进入正常模式并用绿灯指示 ID；失败时橙灯快闪

## 指示灯

异常状态下电调关闭输出。多个警告或异常同时存在时，显示闪烁次数最少的状态；异常优先于警告。

| 类别 | 指示 | 含义 |
| --- | --- | --- |
| 正常 | 绿灯每秒闪 N 次 | 当前 ID 为 N，N 为 1～8 |
| 快速设置 ID | 橙灯常亮 | 正在快速设置 ID |
| 电机校准 | 绿灯快闪 | 正在校准位置传感器 |
| PWM 校准 | 绿灯常亮 | 正在校准 PWM 行程 |
| PWM 校准 | 橙灯快闪 | PWM 行程校准失败 |
| 警告 | 橙灯每秒闪 1 次 | 电机温度 ≥125 ℃ |
| 警告 | 橙灯每秒闪 2 次 | CAN 总线上存在重复 ID |
| 警告 | 橙灯每秒闪 3 次 | PWM 输入不在最小值 |
| 异常 | 红灯常亮 | 无法访问电机存储芯片或电机不匹配，仅开机自检 |
| 异常 | 红灯每秒闪 1 次 | 供电电压过高，仅开机自检 |
| 异常 | 红灯每秒闪 2 次 | 三相线未接入 |
| 异常 | 红灯每秒闪 3 次 | 7-Pin 线中的位置传感器数据丢失 |
| 异常 | 红灯每秒闪 4 次 | 电机温度异常或 ≥180 ℃ |
| 异常 | 红灯快闪 | 位置传感器校准失败 |

温度保护可在 RoboMaster Assistant 中开关。开启时，温度超过 125 ℃会提示并关闭输出；关闭时，125～180 ℃不提示且不关闭输出，达到 180 ℃仍进入异常状态。

## RoboMaster Assistant

PWM 端口兼作串口调参端口：黑色接地，灰色为电调发送端，白色为电调接收端。调参或升级完成前不要断电或断开连接。

若软件无法识别电调，检查并断开其他使用 FTDI 芯片的升级器、USB 适配器或开发板，只保留当前升级器，然后重新为电调上电并重启软件。
