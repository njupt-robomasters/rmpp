# 轮腿控制原理

---

## 1. 机械结构与坐标

车体左右各有一条腿，每条腿由一套五连杆驱动。五连杆的两个主动杆（AB 和 ED）同轴安装在关节电机 O 处，轮轴 C 是被动端。

**虚拟腿**是从 O 到 C 的等效直线，用极坐标描述：长度 L（腿伸出的距离）和方位角 phi0（C 相对于 O 的方向）。控制器不直接操控连杆，而是对虚拟腿的轴向力 Fn 和摆动力矩 Tt 下指令，再通过 VMC 映射到两个关节电机。

坐标约定：底盘机体系 X 前、Y 左、Z 上。腿角正方向是后摆（腿向车尾偏）。

---

## 2. 五连杆正运动学（`update_leg`）

每帧读取两个主动杆的角度（phi1、phi4）和角速度，求解轮轴 C 的位置和速度，再换算成虚拟腿的 L、phi0 及对应速度 d_L、d_phi0。

推导过程用闭链约束：先用几何法找出 C 的位置，再对约束方程求时间导数得到速度。左右腿镜像安装，坐标换算时分别做符号处理，换算到统一的"车体正下方为零、后摆为正"的相对腿角 rel_theta。

腿倾角 theta = rel_theta + pitch，表示腿相对于竖直方向的偏角，是 LQR 状态的直接输入。

---

## 3. 腿长控制（`control_leg_length`）

腿长控制只做腿长 PD 和横滚补偿，平衡由第 4 节的 LQR 完成。

- 腿长 PD 控制器输出轴向力 Fn，误差为目标腿长减实测腿长，微分直接取伸缩速度 d_L（不差分，避免噪声放大）。
- 重力补偿：每条腿分担一半整车重力的沿腿分量，直接前馈到 Fn，使 PD 控制器只需处理动态误差。
- 气弹簧补偿：气弹簧产生的等效伸腿力从 Fn 中扣除，避免弹簧力被 PD 当成误差持续对抗。
- 横滚补偿：横滚 PD 输出一个腿长修正量，左腿加、右腿减，让车体在横向倾斜时自动调平。

---

## 4. LQR 平衡（`calc_lqr`）

LQR 是整个平衡控制的核心，同时处理前向平衡、航向控制和俯仰稳定。

**状态向量**（10 维）：前向位移、前向速度、航向角、航向角速度、左腿倾角及角速度、右腿倾角及角速度、俯仰角及角速度。

**输出向量**（4 路）：左轮力矩、右轮力矩、左摆动力矩、右摆动力矩。

LQR 增益矩阵依赖当前腿长，离线对不同腿长计算增益后，用左右腿长各 0、1、2 次共 6 项（含 Ll·Lr 交叉项）拟合，运行时代入实时腿长求值，避免查表插值的跳变。

**目标限速**：速度与航向角速度指令在 `set_speed()` 里按"直行上限 = 轮子额定转速 × 轮半径"等比缩小，存储的目标不会超限。

**力矩分配**：姿态稳定（平衡）优先，运动指令（平移、转向）按比例让位。具体做法是把输出分成"姿态组"和"运动组"，在四路力矩的额定区间内，先放满姿态组，再以最大可行比例加入运动组；运动组无解时归零，再整体缩小姿态组。轮端额定区间取电机力矩上限，腿摆额定区间取 2×（关节力矩上限 − 当拍轴向力矩），即两关节各让出余量的一半。

---

## 5. 功率限制

双轮净机械功率上限 power_ref 由上级板下发：leg_up 取超电 `power_chassis_ref`，经板间协议 11 位、0.25 W/LSB 传给 leg_down，2047 表示不限；leg_down 由 FSi6X 接管时直接传 `INFINITY`。限制在力矩分配之后、跳跃空闲（`Jump::State::IDLE`）时执行。

1. 计算双轮净机械功率 P = ω·Tw，ω 为左右轮转速，Tw 为左右轮力矩，驱动为正、制动为负。
2. P ≤ power_ref 时原样下发，制动不受限。
3. 超出时把 (Tw_L, Tw_R) 投影到直线 ω·Tw = power_ref 上，功率恰好降到上限。
4. 轮力矩减少后，两腿摆动力矩按映射 M 补上缺少的俯仰阻尼、撤回原有的旋转速度项。

### 加权方向

轮力矩的改动不孤立：轮上少掉的俯仰与航向反馈要由腿补，腿的改动同样计入代价。设轮力矩减少 d（2 维），腿部映射给出摆动力矩改动 M·d，则四路改动按 LQR 出力权重 R 加权的平方和为

    dᵀ·R_w·d + (M·d)ᵀ·R_l·(M·d) = dᵀ·H·d，  H = R_w + Mᵀ·R_l·M

在约束 ω·d = P − power_ref 下取最小，得

    d = (P − power_ref) · H⁻¹·ω / (ωᵀ·H⁻¹·ω)

方向由 H⁻¹·ω 给出，比例由功率约束唯一确定。R_w、R_l 是 `LQR_R` 的轮、腿两块；腿的补偿经 M 折算进 H，数值上占主要部分（腿长 0.22 m 时 H 对角 921 中有 861 来自腿项）。H 在"两轮同向削减"方向上比"两轮反向削减"贵约 5 倍，因为同向削减要两腿共同补俯仰阻尼，反向削减只让两腿反向出力。

两腿对称、两轮转速相同时 H 对两轮对称，最优方向与 ω 平行，退化为两轮同比例削减；腿长不同或两轮转速不等时方向偏转，可能出现一侧轮减力、另一侧加力，最终仍满足功率约束。

### 腿部映射 M = D·C⁻¹

C 的两列是两轮对俯仰角速度、航向角速度的增益（C(i,0) = k[i][9]、C(i,1) = k[i][3]），把这两个状态误差折算成轮力矩；D 的两列是同一误差折算成的摆动力矩改动量。第一列用两腿稳姿态 LQR 的俯仰角速度增益减去当前总增益，即把轮上丢掉的俯仰阻尼交给两腿；第二列取负，撤回腿原有的旋转速度项。C、D 都由实时腿长求值，M 每拍做一次 2×2 求逆。

### 越界处理

投影点越过轮力矩额定区间时，取功率线上与原点同向缩放的可行点 anchor，从 anchor 向投影点截取到刚好进入区间。两点都在功率线上，削减量被截短，功率仍恰好等于上限。两腿摆动力矩加上 M 乘最终轮缺口后限到关节余量，顶到限幅时力矩与功率约束优先。

关节功率和铜耗不计入 power_ref，由电机本身限幅。

---

## 6. VMC 力映射（`vmc_map`）

VMC（虚拟模型控制）把虚拟腿的轴向力 Fn 和摆动力矩 Tt 映射到两个关节电机的实际力矩。

原理：用机构的力雅可比矩阵建立虚拟力与关节力矩的关系。轴向力在两关节产生大小相等、方向相反的力矩；摆动力矩由两关节同向平分。右腿镜像安装，映射时对摆动力矩取反。

轴向力的折算系数 0.5·L·tan∠OCB（N·m/N）随腿长在 `update_leg` 里一起更新，映射到关节力矩和估算关节余量时各乘一次。

---

## 7. 倒地自救

**倒地检测**：上电默认处于 `FALLEN`，即使车身直立，首次使能也等待批准。站立（`UPRIGHT`）时，任一腿的相对腿角超出 [−63°, 63°]，或横滚绝对值超过 90°，进入 `FALLEN` 等待批准。批准时进入 `RUNNING`，按当时的姿态选方向、用实测腿角初始化目标一次。之后即使姿态仍越界或撤销批准，动作也继续推进；站起完成回到 `UPRIGHT`，跳跃期间保持 `UPRIGHT`，失能立即回到 `FALLEN`。

**自救分两种情形**：

- 正向倒地（横滚 < 90°）：目标腿角持续减小（向前摆），反馈进入 [−60°, 80°] 后转入收腿；收腿把目标移向零，|目标| ≤ 11° 时归零，双腿都进入收腿且反馈回到 ±23° 内判定站起完成。
- 翻倒（横滚 > 90°）：低头为头部着地、抬头为尾部着地。腿向着地方向摆到 [90°, 149°]（镜像侧取负），反馈进入 [90°, 166°] 后双腿就绪，再继续摆到正下方停在 90°，反馈进入 [57°, 106°] 后完成翻转，转入站起流程。

自救期间轮端不输出，摆动力矩由相对腿角 PD 跟踪目标角度；只有站起收腿阶段输出轴向力，目标腿长取 leg_min。

## 8. 跳跃

跳跃分四个阶段，用 `Jump::State` 枚举管理（`IDLE` 表示空闲）：

| 阶段 | 行为 |
|------|------|
| TAKEOFF | 双腿全力伸出（起跳力 + 重力补偿），伸到 leg_max 后进入下一阶段 |
| RETRACT | 全力收腿（不补偿重力，车已离地），收到 leg_min 后进入保持 |
| HOLD | 保持收腿，等待 jump_retract_time 后进入缓冲 |
| BUFFER | 恢复正常腿长控制到 jump_buffer_length，等待 jump_buffer_time 后结束 |

起跳阶段关闭摆动力矩（关节力矩全给伸腿）；收腿和保持阶段关闭轮端（已离地）。四个阶段都不做额定力矩分配与功率限制，四路直接下发由电机自身限幅。上升沿触发（记录在 `jump.last_trigger`），动作期间不排队；失能或倒地时复位。
